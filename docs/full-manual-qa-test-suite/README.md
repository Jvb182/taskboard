# Full manual QA test suite

- Copy [`TEMPLATE.md`](TEMPLATE.md) to a file named `YYYY-MM-DD-taskboard-qa.md` for each test run.
- Fill in tester, version, client build, character, resolution, and build or PR before testing.
- Check a box only after the case passes. Leave failures unchecked and add a row under **Bug reports**. Mark cases you cannot run as **Not run** with a reason.
- Keep dated results as historical records. Update the template when Taskboard behavior or release criteria change.

The [2026-11-09 run](2026-11-09-taskboard-qa.md) preserves the live QA page's checked results, outstanding cases, and notes from the 1.3.0 review. The nine theme screenshots and Custom picker evidence were captured locally during that run.
